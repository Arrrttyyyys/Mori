# Mori supervised-pilot pack

Mori's first real-world use is a **supervised usability and safety pilot**, not autonomous care, diagnosis, psychotherapy, or evidence that dementia is treated. No participant may be enrolled until every required launch gate is signed off.

## Proposed pilot

- 5–10 adults with mild-to-moderate dementia
- 4–6 weeks; 2–3 sessions per week; 10–20 minutes per session
- A trained caregiver or staff supervisor physically present for every session
- A named dementia-care clinical advisor and named safety lead
- No medication, diagnosis, emergency triage, efficacy, or disease-progression claims
